# Bizele Brand Guidelines

## Brand personality

- Intelligent
- Modern
- Creator-focused
- Data-driven
- Premium
- Approachable

## Visual direction

Avoid:
- Generic corporate SaaS appearance
- Excessive gradients
- Template-like sections
- Excessive glassmorphism
- Stock-photo-heavy layouts

Prefer:
- Strong typography
- Distinctive layouts
- Controlled motion
- Generous whitespace
- Editorial-style composition
- Data/AI visual language

## Design Direction

Bizele should feel:

- Intelligent
- Modern
- Human
- Creator-focused
- Premium
- Data-driven
- Connected

Avoid:

- Generic blue SaaS aesthetics
- Excessive glassmorphism
- Excessive gradients
- Neon cyberpunk styling
- Overly futuristic typography
- Stock-photo-heavy layouts
- Generic AI visual clichés

The Bizele logo and plum-to-crimson gradient should remain the primary visual identity.
