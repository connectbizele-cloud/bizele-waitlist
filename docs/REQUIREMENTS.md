# Waitlist Requirements

## Primary objective

Convert visitors into Bizele waitlist registrations.

## User types

Users must select:

- Creator
- Brand / Business

## Required information

### Creator

- Full name
- Email
- Social media handle
- Primary platform

### Brand

- Full name
- Work email
- Brand/business name
- Website
- Company size

## Core functionality

- Landing page
- Product explanation
- Creator/Brand value proposition
- Waitlist CTA
- Registration form
- User-type selection
- Real-time waitlist count
- Successful registration state
- Duplicate registration handling
- Validation
- Error handling
- Mobile responsive UI

## Waitlist count

Display the current number of registered users.

The number must come from the database.

Do not hardcode the number.

## Registration

On successful submission:

1. Validate input.
2. Submit to backend/database.
3. Prevent duplicate registration.
4. Update waitlist count.
5. Display confirmation.
